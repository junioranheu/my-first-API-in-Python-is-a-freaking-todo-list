########## FastAPI — Instalação, Execução e Swagger
- Criar ambiente virtual: python -m venv venv
- Ativar ambiente (Windows): venv\Scripts\activate
- Instalar dependências: pip install "fastapi[standard]" sqlalchemy alembic
- Gerar arquivo de dependências: pip freeze > requirements.txt
- Instalar dependências de projeto existente: pip install -r requirements.txt
- Rodar a API (modo dev): fastapi dev app/main.py
- Acessar Swagger UI: http://localhost:8000/docs

########## Schemas e Validação (Pydantic)
- BaseModel: Classe base para criar DTOs.
- Field(...): Adiciona regras de validação (ex: min_length). O `...` indica obrigatoriedade.
- ConfigDict(from_attributes=True): Permite ler atributos da entidade ORM.
- Padrão: Criar SchemaBase e derivar Create/Update/Response para evitar overposting.

########## Injeção de Dependência e Rotas (FastAPI)
- Depends: Usado nos endpoints para injeção de escopo (ex: db: Session = Depends(get_db)).
- APIRouter: Equivalente ao Controller, agrupa rotas (ex: prefix="/tarefas").
- Decorators: Mapeiam verbos HTTP e parâmetros da URL (@router.get("/{id}")).
- Registro: Usar app.include_router(nome_do_router) no main.py.

########## Banco de Dados (SQLAlchemy e PostgreSQL)
- Instalar driver Postgres: pip install psycopg2-binary
- URL PostgreSQL: postgresql://usuario:senha@host:porta/banco
- EnsureCreated: Base.metadata.create_all(bind=engine) no main.py.

########## Variáveis de Ambiente (.env)
- Instalar pacote: pip install python-dotenv
- Regra de ouro: Adicionar .env ao arquivo .gitignore.
- Carregar variáveis: load_dotenv() e os.getenv("NOME_VARIAVEL").

########## Parâmetros de Rota e Tratamento de Erros
- Path Parameters: Definidos com {} no decorator e tipados na função (ex: id: int).
- HTTPException: Lançado para retornar erros HTTP (ex: raise HTTPException(status_code=404)).
- HTTP 204: Definido no decorator status_code=status.HTTP_204_NO_CONTENT.

########## Relacionamentos no SQLAlchemy (1 para N)
- Lado N (Ex: Tarefa): Criar a coluna de chave estrangeira com `ForeignKey("tabela.id")`.
- Lado N (Ex: Tarefa): Criar navegação com `relationship(back_populates="colecao_no_pai")`.
- Lado 1 (Ex: Usuario): Criar navegação (lista) com `relationship(back_populates="nome_no_filho")`.
- Nota: O `relationship` não vira coluna no banco, serve apenas para o Python navegar entre os objetos.

########## Autenticação e Segurança (Hashing)
- Bibliotecas: pip install "passlib[bcrypt]" pyjwt
- Hashing (passlib): Usar CryptContext(schemes=["bcrypt"]) para gerar e verificar senhas.
- Regra de Ouro Pydantic: O Schema de Resposta (Ex: UsuarioResponse) NUNCA deve conter a senha ou o hash, apenas dados públicos (id, email).

########## Autenticação e JWT (Login)
- Gerar Token: jwt.encode(payload, SECRET_KEY, algorithm="HS256") (requer pyjwt).
- Endpoint Login: Usar OAuth2PasswordRequestForm no Depends() para conectar ao botão "Authorize" do Swagger.
- Formato de Resposta: O endpoint de login deve retornar obrigatoriamente {"access_token": token, "token_type": "bearer"}.

########## Validação Avançada Pydantic
- Limites: Usar `Field(max_length=X, min_length=Y)` para evitar estouro de limite de banco ou criptografia (ex: Bcrypt suporta máx 72 caracteres).

########## Tratamento Global de Erros
- Padrão: Usar `@app.exception_handler(Exception)` no main.py.
- Retorno: Usar `JSONResponse(status_code=500, content={"mensagem": "..."})` para padronizar saídas de erro interno.
