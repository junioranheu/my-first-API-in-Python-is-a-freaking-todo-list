# Arquitetura Base (pasta app/)
# main.py      -> Program.cs (Setup e ponto de entrada)
# database.py  -> Setup do banco (DbContext)
# models/      -> Entidades (EF Core)
# schemas/     -> DTOs (Validação Pydantic)
# routers/     -> Controllers (Endpoints)
# services/    -> Regras de Negócio
